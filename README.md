## 🎯 Catálogo Oficial de Servicios & Demos Interactivas

1. **`01` Páginas Web** — *"Tu negocio, abierto las 24 hs."*
   - Sitios rápidos, prolijos y 100% responsive para celulares y computadoras con la identidad de tu marca, posicionamiento SEO y botón directo a tu WhatsApp.
   - *Proyectos reales:* Levels GYM, MyM Decoraciones, Cesar Aparicio Estilista, BGA Habilitaciones, Krauft Inmobiliaria.

2. **`02` Sistemas de Gestión** — *"Turnos, stock y finanzas ordenados."*
   - Software web a medida que centraliza tu operación diaria: agenda de turnos online, control de productos e inventario, balance financiero y acceso multidispositivo.
   - *Proyectos reales:* Club Natación y Gimnasia, CONFIA-CAR, NutriOliva.

3. **`03` Tienda Online** — *"Vendé online con tu propia tienda."*
   - E-commerce con catálogo interactivo, carrito de compras, integración de pagos (Mercado Pago), alertas de ventas y panel autoadministrable simple.
   - *Proyectos reales:* Nova-SetUp, Fleeswap.

4. **`04` Invitaciones Digitales** — *"Invitaciones 100% Digitales (Calidad Premium)"*
   - Tarjetas digitales interactivas para cumpleaños infantiles, 15 años y eventos con música de fondo con ondas animadas, cuenta regresiva en vivo, ubicación interactiva en Google Maps, mesa de regalos (CBU/Alias) y confirmación RSVP directa a WhatsApp.
   - *Modelos reales:* Cumple 5 de Sofía (K-Pop Rumi), Cumple 18 de Julián (Boca), Cumple 6 de Olivia (Stitch & Angel), XV de Karla (Fiesta), Misa de los 15 de Karla.

5. **`05` Mejora de tu Web** — *"¿Tu web quedó lenta? Mejorémosla."*
   - Auditoría previa y optimización integral bajo 3 pilares: **Velocidad** (carga < 1.2s), **Diseño UI/UX** moderno y adaptado a celulares, y **Nuevas Funcionalidades**.

6. **`06` Revisión de Presupuesto** — *"¿Ya tenés otro presupuesto? Te lo reviso."*
   - Comparativa técnica sin cargo y sin compromiso de presupuestos web de otros proveedores: revisión de alcance, detección de costos ocultos y propuesta optimizada todo incluido.

## ⚡ Rendimiento, Rapidez & SEO

- 🏎️ **CSS Ligero y Optimizado:** Reducción del 78% en tamaño de estilos gracias a utilidades CSS nativas de alto rendimiento (sin sobrecarga de librerías CSS pesadas).
- 📦 **Code Splitting & Lazy Loading:** Carga bajo demanda del modal de ficha técnica (`ServiceDetailModal`) mediante `React.lazy` + `Suspense` para una carga inicial instantánea.
- 🔍 **SEO Técnico Completo:**
  - Metadatos Open Graph y Twitter Cards integrados con el logo oficial (`/Logo_LLDP.png`).
  - Datos estructurados **Schema.org** (`ProfessionalService`, `OfferCatalog` con los 6 servicios y `WebSite`).
  - `sitemap.xml` y `robots.txt` autogenerados y optimizados para Google.
  - Fuentes de Google (`Space Grotesk`, `Plus Jakarta Sans`, `Geist Mono`) cargadas de forma no bloqueante con `display=swap`.
- 🛡️ **Headers de Caché & Seguridad en Vercel:** Configuración en `vercel.json` con caché inmutable para assets estáticos y headers de seguridad (`nosniff`, `DENY`, `strict-origin-when-cross-origin`).

## ⚙️ Instalación y Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/LautaroLeall/Servicios-LLDP.git

# 2. Entrar a la carpeta
cd Servicios-LLDP

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Compilar para producción
npm run build
```
